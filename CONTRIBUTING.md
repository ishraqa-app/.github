# Contributing to Ishraqa projects

1. Read the project's README and open issues.
2. Comment on an issue before starting, so work isn't duplicated.
3. Fork, create a branch, keep changes focused, and add tests.
4. Open a pull request that explains *what* and *why*.
5. A maintainer reviews every PR. Be patient and kind.

Each project may add its own rules in its CONTRIBUTING.md.
